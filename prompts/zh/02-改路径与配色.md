# 提示词模板 · 改现有图的高亮路径、字幕或配色

```
你在 layergraph 仓库里工作（先读 SKILL.md）。改一份现有规格，不要重建。

规格：⟨path/to/layergraph.json⟩

要改的
- 新的高亮路径：⟨X → Y → Z⟩（第二条路径保留 / 删除 / 改为 ⟨…⟩）。
- 字幕：⟨每步新句子，中英⟩；窗口对齐 lit_at（节点亮前约 0.2 秒出现，下一步亮前结束）。
- 配色：⟨例如 品牌底色 #123456、路径暖白、打印用浅色预设⟩。

做法
1. 规格里只改 highlight / captions / camera（取景没问题就保留 "auto"）。
2. 配色：把 presets/⟨ivory-gold|ivory-indigo|slate-gold|midnight|obsidian-gold⟩.json 复制成 presets/⟨name⟩.json，在里面改键（bg、fog、node.tints、
   lit.node / glow / tube、label.*、hud.*）。meta.preset 指到 "presets/⟨name⟩.json" 或用 --preset。改完
   grep 新预设里被替换的旧色值；旧色不能残留在任何地方。
3. `validate`，再 `test -o out/⟨name⟩` 看：远景（t≈0.5）、每次点亮、封面帧（`cover --t ⟨最后一次点亮 + 1.5⟩`）、末帧。
   核对比：路径必须是画面里唯一饱和的东西（深底上也是唯一发光的）；米白预设上字幕强调词在白卡上要到 4.5:1。
4. 渲染（`render`，双语规格两种语言都出）并 `strip`。
5. 报告改了什么（规格各节与预设键的 diff）和新产出的路径。
```
