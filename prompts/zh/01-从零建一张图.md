# 提示词模板 · 从零建一张 roadmap3d 动画

在 `roadmap3d` 仓库里粘给 Claude Code / Cursor，替换 ⟨…⟩。

```
你在 roadmap3d 仓库里工作（先读 SKILL.md）。建一份新的动画规格并渲染。

数据
⟨贴节点清单 / CSV / Markdown 表：名称、所属层、所属分组、可选深度级别、可选父节点⟩
⟨贴边，或描述规则，例如「每个零部件供给用到它的组件」「每个任务卡住它后面的任务」⟩

故事
- 要按顺序亮起来的高亮路径：⟨A → B → C⟩（A 是故事起点；C 是终点）。
- 每一步一句字幕（中英）：⟨…⟩
- 可选尾段：第二条路径 ⟨…⟩ 与一行尾字 ⟨…⟩。
- 时长 ⟨21⟩ 秒，预设 ⟨ivory-gold|ivory-indigo|slate-gold|midnight|obsidian-gold⟩，语言 ⟨zh, en⟩，品牌行 ⟨标题 / 副题⟩。

做法
1. 按 schema/roadmap3d.schema.json 写 examples/⟨name⟩/roadmap3d.json。层自下而上，分组作车道，
   只有数据本身有序数级别时才用深度。父节点旁的子项用 minor，附件用 leaf。
2. 所有可见文本双语（{"zh","en"}）。字幕 ≤ 40 字；*词* 表示强调。
3. 跑 `node src/cli.mjs validate …`，改掉全部错误，解释保留的警告。
4. 跑 `node src/cli.mjs test … -o out/⟨name⟩` 并看图。报告：远景里路径是否可读、标签是否重叠、字幕是否落框、
   轴标在远景与近景是否清楚。调 lit_at / 字幕 / 镜头（没有理由就用 "auto"），直到干净。
5. 两种语言各渲染一版：`render … --lang zh -o out/⟨name⟩-zh`、`--lang en`，再 `strip`。
6. 交回：规格路径、out/ 路径、拼图与 GIF，以及五行内的选择说明（分层、路径时序、预设）。
不要为改内容去动 src/engine.html 或预设；内容只属于规格。
```
